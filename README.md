# Gather & Flame

Public preview of Gather & Flame, a cooking and entertaining app.

## Deploy to Netlify

Import the GitHub repository into Netlify. Build command: leave blank. Publish directory: `.`.

## Current limitations

The My Kitchen and Party Planner sections use browser localStorage. This is **not** account-based privacy or synchronisation. Do not store sensitive data. Before public release, add authentication, per-user data access controls and cloud storage.
